Sobre el proyecto

Tecnologías Web aplicadas al monitoreo de sensores en tiempo real.

¿Qué es este proyecto?

Plataforma web desarrollada en la asignatura de Tecnologías Web. Se integra con hardware físico para monitorear sensores en tiempo real, mostrando los datos de forma clara y accesible desde cualquier navegador.

Tecnología utilizada

El sistema utiliza el microcontrolador ESP32 como nodo de captura de datos, trabajando con un sensor de gas MQ-4. La comunicación entre el hardware y la plataforma se gestiona a través de protocolos estándar de red.
